# 🌸 Telegram Modular Femboy

Минималистичный модульный юзербот **Femboy** для Telegram на базе Telethon с поддержкой Gemini AI.

---

## 📁 Структура проекта

```text
c:\userbotik\hyila\
│
├── config.py             # Конфигурация (API_ID, API_HASH, префикс)
├── main.py               # Главный файл запуска и авто-установки библиотек
├── start.bat             # Быстрый запуск (Windows)
├── requirements.txt      # Список зависимостей
├── 1.jpeg                # Фото баннера для команды .info
│
├── core/                 # Ядро Femboy
│   ├── __init__.py       # Декоратор @command
│   ├── loader.py         # Менеджер динамической загрузки/выгрузки
│   └── utils.py          # Вспомогательные функции
│
└── modules/              # 📂 Папка с исполняемыми модулями
    ├── ai.py             # .ai, .aion, .aioff, .aimode (Gemini с контекстом, защитой и режимами)
    ├── ping.py           # .ping (замер скорости отклика)
    ├── restart.py        # .restart (перезапуск процесса)
    ├── info.py           # .info (профиль с баннером 1.jpeg, RAM, CPU, аптайм)
    ├── eval.py           # .eval, .term (исполнение Python и Shell команд)
    ├── purge.py          # .purge, .del (быстрое удаление сообщений)
    ├── type.py           # .type (анимация печатной машинки)
    ├── id.py             # .id (информация о чате, пользователе, ID)
    ├── moderation.py     # .ban, .unban, .mute, .unmute (модерация в ЛС/чатах)
    ├── dmess.py          # .dmess (логер удаленных сообщений)
    ├── help.py           # .help (справка по командам)
    └── modmanager.py     # .load, .unload, .reload, .modules (управление модулями)
```

## 🛠 Доступные команды

### 🤖 Нейросеть (Gemini AI)
| Команда | Описание |
|---|---|
| `.ai <вопрос>` | Задать вопрос нейросети (сохраняет контекст диалога для каждого пользователя и знает его имя) |
| `.ai` (в ответ на сообщение) | Прочитать сообщение пользователя и сгенерировать осмысленный ответ на него |
| `.aipub` | Переключить публичный режим (разрешить/запретить другим людям в чатах использовать AI) |
| `.aion` / `.aioff` | Включить / выключить авто-ответ нейросети на реплаи к вашим сообщениям |
| `.aimode` | Посмотреть текущий режим личности AI и список доступных |
| `.aimode femboy` | Включить режим милого аниме-фембойчика («Хозяин», кавайные эмодзи, Nya~) |
| `.aimode murino` | Включить Муринский язык из ТикТока («ч», «друн», «сырность», «The Fog») |
| `.aimode default` | Вернуть стандартный режим ассистента |

### ⚙️ Система и утилиты
| Команда | Описание |
|---|---|
| `.info` | Карточка профиля с фото 1.jpeg, аптаймом, RAM и CPU |
| `.ping` | Замеряет отклик `Ping: xx.xx ms` |
| `.restart` | Перезапускает Femboy (`🔄 Restarting Femboy...`) |
| `.eval <code>` | Асинхронное выполнение Python кода |
| `.term <cmd>` | Выполнение системных команд в терминале |
| `.purge` / `.del` | Быстрое удаление сообщений |
| `.type <текст>` | Анимация эффекта печатной машинки |
| `.id` | Показывает ID чата, пользователя и сообщения |
| `.dmess` / `.dmess @channel` | Логер удаленных сообщений в Избранное |
| `.ban` / `.unban` / `.mute` / `.unmute` | Команды модерации |
| `.modules` / `.help` / `.reload` | Управление модулями |
